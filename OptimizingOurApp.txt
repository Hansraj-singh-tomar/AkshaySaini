2. Breakdown Large JS file into chunks
    -> If we are developing large scale application we must breakdown our application into smaller pieces  
        This process is known as chinking, code spliting, Dynamic bundling, lazy loading, ondemand loading, Dynamic import so many name for it.
    -> In that when we go to our grocery page then only grocery code will their in our app/application
    -> This lazy function create a different js file for us but it render 
        it with our main js file to resolve it we will use suspense with lazy
        suspense will render it when we go to grocery component
Example - import {lazy, Suspense} from "react";
            const Grocery = lazy(() => import("./components/Grocery.js"));
            <Suspense fallback={<h1>Loading....</h1>}><Grocery/></Suspense>
